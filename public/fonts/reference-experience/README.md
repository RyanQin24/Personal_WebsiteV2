# Experiences reference font

`inter-latin-variable.woff2` is the exact Latin variable font served by
https://work.jaryddiamond.com/ when inspected on 2026-10-29.

- Family: **Inter Variable**
- Style: normal
- Weight range: **100–900**
- Font asset: https://work.jaryddiamond.com/assets/inter-latin-wght-normal-Dx4kXJAl.woff2
- Reference stylesheet: https://work.jaryddiamond.com/assets/app-BQn2OoVR.css
- Upstream font project: https://github.com/rsms/inter
- License: SIL Open Font License 1.1, included in `LICENSE.txt` from
  https://raw.githubusercontent.com/rsms/inter/master/LICENSE.txt

The reference stylesheet uses `font-display: swap`. Its Work Experience role
titles inherit a 16px font size and 24px line height, with weight 500. Its
section heading, dates, and location text use 14px with a 20px line height;
the section heading has weight 500, and dates/locations use weight 400.
