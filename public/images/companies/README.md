## Official organization assets

These assets identify the organizations in Ryan's Experiences page. The logos
remain the property of their respective organizations.

| Local file | Official organization page | Asset source | Display ratio |
| --- | --- | --- | --- |
| `amd.svg` | https://www.amd.com/en.html | https://www.amd.com/content/dam/code/images/header/amd-header-logo.svg | `139.72 / 33.32` |
| `ats.svg` | https://atsautomation.com/ | https://atsautomation.com/wp-content/uploads/sites/2/2024/07/atsco-logo-p.png | `173 / 37` |
| `wsp.svg` | https://www.wsp.com/en-gl | The official page's inline `a-wsp-logo` header SVG | `57.372 / 27.285` |
| `midnight-sun.png` | https://www.uwmidsun.com/ | https://images.squarespace-cdn.com/content/v1/5bb8c0b37980b31516c7b7fa/1538834812911-3CN0JNGU0X4XSZHDHDNU/Team+Logo+LONG.png?format=1500w | `1500 / 337` |

`amd.svg` and `wsp.svg` are the original header graphics. `ats.svg` embeds the
original transparent PNG (`ats.png`) unchanged, with an SVG viewport that excludes
the PNG's empty top/bottom margins. These three graphics can be displayed as alpha
masks using the page's text color, which remains readable in light and dark mode.

Midnight Sun's logo includes a dark banner, white lettering, and a yellow sun.
Display `midnight-sun.png` in its original colors instead of using an alpha mask;
an alpha mask would remove the lettering inside the banner. Its banner keeps the
logo legible on both light and dark backgrounds.
